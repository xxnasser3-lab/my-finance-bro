# بوصلة · My Finance Bro

تطبيق ويب يتثبّت على الجوال (PWA) لتتبع فلوسك وديونك وخطة التحرر منها. عربي وإنجليزي، ويتقلب اتجاهه حسب اللغة.

- **بياناتك على جوالك بس**، مشفّرة بـ AES-256 بكلمة مرور تختارها. ما فيه سيرفر، وما تنرفع البيانات لـ GitHub.
- المستودع فيه **الكود بس**. حتى لو كان Public، ما أحد يقدر يشوف أرقامك.

## وش فيه

- **الرئيسية**: إجمالي الأرصدة، صافي الثروة، المتاح للصرف حتى الراتب، ميزانية اليوم، رسم الصرف مقابل الميزانية مع التوقع، المدفوعات القادمة.
- **المحفظة**: كل حساب وبطاقة ورصيدها. شكل البطاقة (البنك، النوع، اللون، أو صورة)، وبيانات البطاقة كاملة مع زر نسخ.
- **البطاقات الائتمانية**: سياسة البطاقة، الكشف والحد الأدنى وآخر موعد، استخدام الحد، مقارنة طرق السداد والأرباح.
- **العمليات**: مصروف ودخل وتحويل، تصنيفات تضيفها بنفسك مع تصنيفات فرعية، ربط بالرحلات والديون.
- **الديون**: قروض، تابي وتمارا وتساهيل بالأقساط، أشخاص بأفتار أو صورة (علي لهم / لي عندهم).
- **الخطة**: الأعلى تكلفة أولاً أو الأصغر أولاً، مسار الديون، "ماذا لو"، توزيع الراتب والبونص، صندوق الطوارئ.
- **الالتزامات والاشتراكات**: تقويم شهري، وبطاقة افتراضية للاشتراكات.
- **التقارير**: أسبوعية وشهرية مع التنقل بين الفترات، الدخل مقابل المصروف، حسب التصنيف.
- **الرحلات**: كم صرفت على كل رحلة، يوم بيوم وحسب التصنيف.

## التشغيل محلياً

```bash
npm install
npm run dev        # http://localhost:5173/my-finance-bro/
npm run build      # النسخة النهائية في dist/
```

## النشر على GitHub Pages (مجاني)

1. في المستودع: **Settings → Pages → Source: GitHub Actions**.
2. أي push على `main` أو فروع `claude/**` يبني التطبيق وينشره تلقائياً (`.github/workflows/deploy.yml`).
3. الرابط: `https://<اسم-المستخدم>.github.io/my-finance-bro/`
4. على الآيفون افتح الرابط في Safari، ثم **مشاركة ← إضافة إلى الشاشة الرئيسية**.

> GitHub Pages المجاني يحتاج المستودع يكون **Public**. هذا آمن لأن المستودع فيه الكود بس.
> إذا تبي المستودع Private بدون دفع، انشر من [Cloudflare Pages](https://pages.cloudflare.com):
> - Build command: `npm run build`
> - Output: `dist`
> - متغير البيئة: `BASE_PATH=/`

## النسخ الاحتياطي

- **نسخة الآن** (الإعدادات): يطلع ملف مشفّر تحفظه في iCloud Drive أو الملفات.
- **استعادة نسخة**: تختار الملف وتكتب كلمة مرور النسخة.
- **Google Drive** (اختياري ومجاني): نسخة مشفّرة في مجلد مخفي خاص بالتطبيق داخل حسابك، ويحتفظ بآخر 30 نسخة.

### تجهيز Google Drive (مرة وحدة، حوالي 10 دقائق)

1. ادخل <https://console.cloud.google.com> وسوِّ مشروع جديد. ما يطلب بطاقة.
2. **APIs & Services → Library**: فعّل **Google Drive API**.
3. **OAuth consent screen**:
   - اختر External.
   - اكتب اسم التطبيق وإيميلك.
   - في Test users أضف إيميلك.
4. **Credentials → Create credentials → OAuth client ID**:
   - النوع: **Web application**.
   - في **Authorized JavaScript origins** أضف `https://<اسم-المستخدم>.github.io`.
5. انسخ الـ **Client ID** وحطه في التطبيق: **الإعدادات ← Google Drive**.

أول مرة تضغط "ربط ورفع نسخة"، Google بيقول إن التطبيق "غير موثّق". هذا طبيعي لأنه تطبيقك الشخصي: اضغط **Continue**.

## الأمان

- **التشفير**:
  - كلمة المرور تتحول لمفتاح بـ PBKDF2-SHA256 (310,000 تكرار).
  - البيانات تتشفّر بـ AES-GCM 256.
  - كلمة المرور نفسها ما تنحفظ.
- **Face ID**:
  - يفتح نسخة من المفتاح محفوظة على الجهاز، وما تقدر تنسحب منه.
  - وأنت تستخدم التطبيق، كشف بيانات البطاقة يطلب Face ID.
- **القفل التلقائي**: التطبيق يتقفل بعد 5 دقائق في الخلفية.
- ⚠️ **كلمة المرور ما تنسترجع.** إذا نسيتها، نسخك الاحتياطية ما تنفتح.

## التقنيات

Vite + Preact + TypeScript، `vite-plugin-pwa` (للعمل بدون إنترنت)، IndexedDB، Web Crypto، WebAuthn. كل الرسوم البيانية مبنية بـ SVG بدون مكتبات إضافية.
